## 1. Le français en images

**Regardez les illustrations.**

[Illustrations : 1. un homme souriant tient une frite au-dessus de sa bouche, une barquette de frites à la main ; 2. un homme frappé par un éclair ; 3. un homme debout, la tête dans les nuages.]

**a.** Sur chaque image, que fait l'homme ?
**b.** Retrouvez l'expression qui correspond à chaque image.
*avoir la frite – avoir la tête dans les nuages – avoir le coup de foudre*
**c.** Retrouvez le sens figuré de ces expressions.

| | | |
|---|---|---|
| avoir la tête dans les nuages : | ☐ voyager | ☐ rêver |
| avoir le coup de foudre : | ☐ tomber amoureux | ☐ tomber malade |
| avoir la frite : | ☐ avoir faim | ☐ être en forme |

Vérifiez vos réponses dans le dictionnaire.

**C'est à vous !** [icône : bulles de dialogue]
Formez des groupes. Pensez à une expression dans votre langue puis expliquez-la ou dessinez-la. Les autres personnes du groupe essaient de deviner son sens.

[Encadré « Mots et expressions » :]

**Le dictionnaire**
• *n.f.* = nom féminin
• *n.m.* = nom masculin
• *adj.* = adjectif
• *inv.* = invariable
• sens propre = sens premier d'un mot ou expression
→ *une clé pour ouvrir la porte*
• sens figuré = sens imagé d'une expression
→ *une clé = une solution*
