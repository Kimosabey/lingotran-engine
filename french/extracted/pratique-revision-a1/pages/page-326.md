28 • Le passé composé

> **• Le passé composé avec « être »**
>
> **Je suis allé(e) au supermarché. Elle est arrivée à la gare. Vous êtes sorti(e)(s) en discothèque.**
> **Ils sont partis hier soir. Elles sont venues avec nous.**
>
> • Les verbes qui forment le passé composé avec être sont :
> - tous les verbes pronominaux ;
> - les verbes de mouvement, d’état ou de changement d’état : naître, aller, monter, arriver, (re)venir, (r)entrer, passer, rester, partir, sortir, descendre, tomber, mourir, décéder.
>
> • Avec l’auxiliaire être, le participe passé s’accorde avec le sujet : *il est allé* ; *elle est all**ée***.
