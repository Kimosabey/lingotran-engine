### 197 Reliez les éléments pour former des phrases.

| | |
|---|---|
| a. Les voitures roulent | 1. dans le lac. |
| b. Les gens marchent | 2. dans la ferme. |
| c. Les touristes se baignent | 3. dans la rivière. |
| d. Les pêcheurs pêchent | 4. des œufs. |
| e. Les poules pondent | 5. dans les vignes. |
| f. Les cochons sont | 6. sur les routes. |
| g. Les vaches donnent | 7. du lait. |
| h. Il y a du raisin | 8. sur les chemins. |

d. *un bureau* / *une entreprise*
e. *un quartier* / *une banlieue*
f. *une forêt* / *un parc*
