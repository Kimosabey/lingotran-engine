# 27 • Le futur proche

<!-- running header -->
Grammaire/Conjugaison

> **• Emploi et formation du futur proche**
>
> **Je vais parler. Elle va venir vite. Vous allez danser.**
>
> • On utilise le futur proche pour des actions immédiates ou qui vont se passer dans un futur proche.
> • Le futur proche se forme avec le verbe aller* au présent + verbe à l’infinitif.
> \* Pour la conjugaison du verbe aller au présent, voir page 203.
