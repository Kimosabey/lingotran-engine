# 16 • Verbes courants : « être », « avoir », « aller » et « faire »

<!-- running header -->
Grammaire/Conjugaison

> **• Le présent du verbe « être »**
>
> • C’est un verbe irrégulier.
>
> **Je suis ; tu es ; il/elle/on est ; nous sommes ; vous êtes ; ils/elles sont.**
>
> [main / attention] - es et est se prononcent de la même façon : [e].
>
> - Liaison obligatoire : vous‿êtes [vu zet] ; on‿est [õne]

### 402 Reliez les éléments comme dans l’exemple.

| | |
|---|---|
| a. Il | 1. sont amies. |
| b. Vous | 2. est acteur. |
| c. Ils | 3. suis à Madrid. |
| d. Tu | 4. êtes étudiante ? |
| e. Nous | 5. sont marocains. |
| f. Je | 6. est ingénieure. |
| g. Elles | 7. es en forme. |
| h. Elle | 8. sommes en vacances. |

(marked, example: a → 2)
