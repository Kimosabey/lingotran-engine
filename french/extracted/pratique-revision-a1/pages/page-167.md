### 336 Écrivez des groupes de mots comme dans l’exemple.

Exemple : le château / le maire → le château du maire

a. le livre / l’élève → ___
b. le sac / la directrice → ___
c. le bureau / le président → ___
d. la robe / la mariée → ___
e. le costume / le marié → ___
f. le bouquet / les professeurs → ___
g. les cadeaux / les invités → ___
h. l’emploi du temps / les étudiants → ___

### 338 Complétez avec « à la », « au », « à l’ » ou « aux ».

Exemple : J’ai mal à la gorge.

a. J’ai mal ___ dents.
b. J’ai mal ___ tête.
c. J’ai mal ___ épaule.
d. J’ai mal ___ dos.
e. J’ai mal ___ pieds.
f. J’ai mal ___ jambes.
g. J’ai mal ___ main.
h. J’ai mal ___ ventre.

### 339 Entourez la forme correcte.

Exemple : Vous venez *à la* / *de la* / *du* magasin. (marked, example: du)

a. Ma fille joue *au* / *de la* / *du* football.
b. Nous allons *au* / *à l’* / *du* restaurant chinois.
c. Ils ont mal *à l’* / *de l’* / *du* estomac.
d. Elle arrive *au* / *à la* / *du* station de métro.
e. Ce sont les livres *aux* / *de l’* / *des* étudiants.
f. Elles sortent *au* / *de la* / *du* musée Picasso.
g. Nous revenons *à la* / *du* / *des* cinéma à pied.
h. C’est la voiture *à la* / *de la* / *du* voisine.
