## 10 Amuse-toi bien!

**Now I can ...**

**[A1 (inferred)]**

- *talk about sport*

*Est-ce que tu aimes le sport?* — Do you like sport?

*Je fais ...* — I ...

| French | English |
| --- | --- |
| *du cyclisme/du vélo.* | go cycling. |
| *du roller.* | go roller blading. |
| *du skate.* | go skate-boarding. |
| *du ski.* | go skiing. |
| *du VTT.* | go mountain-biking. |
| *de la danse* | go dancing. |
| *de la gymnastique.* | do gymnastics. |
| *de la natation.* | go swimming. |
| *de la planche à voile.* | go wind-surfing. |
| *de la voile.* | go sailing. |
| *de l'équitation.* | go horse-riding. |
| *des promenades.* | go walking. |

*Je joue ...* — I play ...

| French | English |
| --- | --- |
| *au basket.* | basketball. |
| *au volley.* | volleyball. |

- *talk about music*

*Je joue ...* — I play ...

*J'aime la musique, mais je ne joue pas d'un instrument.* — I like music, but I don't play an instrument.
