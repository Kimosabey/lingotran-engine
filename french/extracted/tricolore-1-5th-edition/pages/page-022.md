**Masculine and feminine**

Before a **masculine** word …
- use **un** for 'a', e.g. **un garçon, un livre**
- use **le** for 'the', e.g. **le garçon, le livre**

Use **il** to say 'he' or 'it'.

Before a **feminine** word …
- use **une** for 'a', e.g. **une fille, une règle**
- use **la** for 'the', e.g. **la fille, la règle**

Use **elle** to say 'she' or 'it'.
