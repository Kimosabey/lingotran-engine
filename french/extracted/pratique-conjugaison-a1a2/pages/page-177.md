Les verbes pronominaux

**[A1 (inferred)]**
### 492 Complétez avec le pronom qui convient.

Exemple : Arrête-toi ici !

a. Préparons ___ !
b. Adaptez ___ !
c. Promène ___ !
d. Calmez ___ !
e. Réveillons ___ !
f. Entraînez ___ !
g. Lève ___ !
h. Dépêche ___ !

**[A1 (inferred)]**
### 493 Complétez avec la bonne terminaison.

Exemple : Amusez-vous bien !

a. Calm ___ toi !
b. Expliqu ___ vous !
c. Install ___ nous !
d. Organis ___ toi !
e. Mari ___ vous !
f. Réveill ___ vous !
g. Arrêt ___ nous !
h. Rappell ___ toi !

**[A1 (inferred)]**
### 494 Reliez.

| | |
|---|---|
| a. Prends une chaise | 1. Mettez-vous à l’aise ! |
| b. Entre bons voisins, | 2. réunissons-nous ! |
| c. Vous n’avez pas faim ? | 3. Inscrivez-vous à un club de gym ! |
| d. Pour régler tous ces problèmes, | 4. Alors, entraîne-toi ! |
| e. Faites comme chez vous ! | 5. Servez-vous ! |
| f. Restez en forme ! | 6. Ne vous perdez pas ! |
| g. Tu veux gagner cette compétition ? | 7. rendons-nous service ! |
| h. Suivez le plan. | 8. et assieds-toi ! |

(marked, example: c → 5)

**[A1 (inferred)]**
### 495 Changez le présent de l’indicatif en impératif présent.

Exemple : Vous vous réunissez demain. → Réunissez-vous demain !
