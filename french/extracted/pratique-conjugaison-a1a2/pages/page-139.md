*Être* ou *avoir* ?

**[A1 (inferred)]**
### 389 Cochez si le verbe se conjugue au passé composé avec être ou avec avoir.

Exemple : Passer un bon moment. *1. être* / *2. avoir* (marked, example: 2. avoir)

a. Monter ses valises. *1. être* / *2. avoir*
b. Sortir d’un immeuble. *1. être* / *2. avoir*
c. Descendre à la cave. *1. être* / *2. avoir*
d. Monter dans le train. *1. être* / *2. avoir*
e. Sortir son porte-monnaie. *1. être* / *2. avoir*
f. Passer par l’autoroute. *1. être* / *2. avoir*
g. Descendre les Champs-Élysées. *1. être* / *2. avoir*
h. Retourner sa veste. *1. être* / *2. avoir*

**[A1 (inferred)]**
### 390 Reliez.

| | |
|---|---|
| a. Nous sommes tombés amoureux | 1. mais on n’est pas entré dans le château. |
| b. Ils étaient anxieux | 2. et il a passé trois mois à l’hôpital. |
| c. On a visité les jardins | 3. quand ils ont passé la frontière. |
| d. Il a eu un grave accident | 4. j’ai vu cette jolie paire de chaussures. |
| e. Quand je suis passée devant la boutique | 5. et tu les as mis sous le balcon ? |
| f. Tu as rentré les meubles du jardin | 6. quand on nous a présenté l’un à l’autre. |

(marked, example: b → 3)
