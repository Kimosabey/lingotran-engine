*Être*

**[A1 (inferred)]**
> **• La forme négative**
>
> **Tu n’es pas là samedi ?**
>
> Pour mettre le verbe à la forme négative, on met *ne* avant le verbe et *pas* après le verbe.
>
> [main / attention] *Ne* devient *n’* devant une voyelle.

**[A1 (inferred)]**
### 8 Mettez à la forme négative.

Exemple : Je ne suis pas d’accord.

a. Il ___ est ___ sympathique.
b. Elles ___ sont ___ amies.
c. Tu ___ es ___ sérieux ?
d. Ce ___ est ___ possible !
e. Nous ___ sommes ___ surpris.
f. On ___ est ___ là demain.
g. Vous ___ êtes ___ professionnels !

**[A1 (inferred)]**
> **• *C’est* et *ce sont***
>
> **C’est ma sœur.**
>
> **Ce sont mes amis.**
>
> *C’est* est suivi d’un nom ou d’un adjectif au singulier.
>
> *Ce sont* est suivi d’un nom au pluriel.
>
> [main / attention] Exceptions : *C’est vous ! C’est nous !* mais : *Ce sont eux ! Ce sont elles !*
>
> À l’oral on utilise plus souvent *C’est*.

**[A1 (inferred)]**
### 9 Complétez la colonne de droite avec *C’est* ou *Ce sont* puis reliez.

| | |
|---|---|
| a. Qui est-ce ? | 1. C’est moi ! |
| b. Qu’est-ce que c’est ? | 2. ___ mes parents. |
| | 3. ___ tes affaires. |
| | 4. ___ elles ! |
| | 5. ___ une tablette. |
| | 6. ___ ma cousine. |
| | 7. ___ des photos. |

(marked, example: a → 1)
