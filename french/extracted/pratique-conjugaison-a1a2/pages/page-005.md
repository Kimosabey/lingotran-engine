# 01 • Le présent de l’indicatif des verbes *être* et *avoir*

## *Être*

> **• Le présent du verbe *être***
>
> Il est irrégulier.
>
> **Je suis, tu es, il/elle/on est, nous sommes, vous êtes, ils/elles sont.**
>
> Notez qu’il n’y a pas de différence de prononciation entre *es* et *est*.
>
> « On » remplace souvent « nous » à l’oral mais il est conjugué comme une 3ᵉ personne du singulier.
>
> [main / attention] Deux liaisons importantes : « on‿est » [n] et « vous‿êtes » [z].

**[A1 (inferred)]**
### 1 Reliez les éléments comme dans l’exemple.

| | |
|---|---|
| a. Tu | 1. est grande. |
| b. Elle | 2. êtes marié ? |
| c. Il | 3. sommes le 14 juillet. |
| d. Nous | 4. es en vacances. |
| e. Ils | 5. est fatigué. |
| f. Je | 6. suis française. |
| g. Vous | 7. sont sympathiques. |

(marked, example: a → 4)

**[A1 (inferred)]**
### 2 Complétez avec *est* ou *es*.

Exemple : Yvan est bilingue.

a. C’ ___ intéressant.
b. Tu ___ jeune.
c. On ___ prêts.
d. Sophia ___ jolie.
e. Tout le monde ___ là ?

**[A1 (inferred)]**
### 3 Mettez dans l’ordre.

Exemple : questions / . / Ces / ridicules / sont → Ces questions sont ridicules.

a. technicien / est / Il / . → ___
b. sommes / . / enchantés / Nous → ___
c. bon / Vous / . / médecin / êtes / un → ___
d. C’ / américain / acteur / est / . / un → ___
e. Tu / de / ? / pays / quel / es → ___
f. La / est / très / belle / . / musique → ___
g. en / suis / Je / forme / ! → ___
h. baskets / . / sont / Ces / chères → ___
