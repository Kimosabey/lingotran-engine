12 • Le futur de l’indicatif

**[A2 (inferred)]**
### 439 Reliez.

| | |
|---|---|
| a. Si tu veux étudier à l’université, | 1. il faudra être sûr que c’est vrai. |
| b. Quand elle saura nager, | 2. Vous saurez si c’est possible. |
| c. Téléphonez-lui ! | 3. ils voudront des preuves. |
| d. Je devrai m’entraîner | 4. si je veux rester dans l’équipe. |

**[A2 (inferred)]**
### 441 Complétez avec les terminaisons.

Exemple : Est-ce que vous pourrez venir ?

a. Tout le monde devr ___ assister à cette conférence.
b. Il faudr ___ prévenir votre famille.
c. Nous ne pourr ___ pas vous satisfaire totalement.
d. Tous nos amis voudr ___ être là.
e. Quand est-ce que je saur ___ si je suis reçu ?
f. Comment est-ce qu’ils pourr ___ le reconnaître ?

### 442 Répondez avec les verbes étudiés comme dans l’exemple.
