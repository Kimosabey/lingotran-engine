**[A1 (inferred)]**
### 92 Mettez dans l’ordre.

Exemple : peut / Elle / . / scandale / faire / un → Elle peut faire un scandale.

a. Je / vous / peux / demain / voir / ? → ___
b. Tu / prêter / ? / me / peux / euros / vingt → ___
c. article / On / peut / . / garantir / cet → ___
d. peut / comprendre / pas / . / ne / Il → ___
e. Vous / TGV / . / prendre / le / pouvez → ___
f. pouvons / ici / stationner / . / Nous → ___
g. Vous / un / pouvez / chèque / . / faire → ___
h. peuvent / ? / document / le / Ils / relire → ___

**[A1 (inferred)]**
### 93 Répondez à la forme négative.

Exemple : Nous pouvons venir demain ? → Non, vous ne pouvez pas venir demain.

a. Tu peux me téléphoner ce soir ? → ___.
b. Ils peuvent faire moins de bruit ? → ___.
c. On peut dîner sans réservation ? → ___.
d. Nous pouvons nous installer à cette table ? → ___.
e. Elle peut s’acheter un scooter ? → ___.
f. Vous pouvez être présents à la réunion ? → ___.

**[A1 (inferred)]**
### 94 Posez des questions avec le verbe *pouvoir*.

Exemple : Je / avoir une réduction. → Est-ce que je peux avoir une réduction ?

a. Tu / lire ce mail. → ___
b. Ils / venir au concert. → ___
c. Vous / envoyer ce papier. → ___
d. Nous / vous voir lundi. → ___
e. Elles / passer cet examen. → ___
f. On  / vous téléphoner. → ___

**[A1 (inferred)]**
### 95 Complétez avec *être* et *pouvoir*.

Exemple : Si vous êtes libres nous pouvons sortir ensemble.

a. Si le service ___ bon, on ___ laisser un pourboire.
b. Si vous ___ raisonnable, vous ___ sortir.
