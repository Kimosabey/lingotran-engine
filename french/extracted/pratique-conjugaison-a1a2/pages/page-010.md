01 • Le présent de l’indicatif des verbes *être* et *avoir*

**[A1 (inferred)]**
### 18 Complétez le dialogue avec le verbe *avoir* au présent.

– J’ai (a) de la fièvre !
– Mais non tu n’ ___ (b) pas de température.
– Mais j’ ___ (c) froid ! On ___ (d) froid dans cette maison ! Il n’y ___ (e) pas de chauffage ?
– Si ! Il y ___ (f) du chauffage. Tu ___ (g) un gros rhume, c’est tout !

**[A1 (inferred)]**
### 19 Complétez avec la forme qui convient : *n’a pas* ou *n’y a pas*.

Exemple : Il n’y a pas beaucoup de banques dans cette rue.

a. Jacques ___ de chance.
b. Il ___ de mot anglais dans cette phrase.
c. Dans cette ville, il ___ de parc.
d. Aujourd’hui, il ___ de chance.
e. On ___ le code d’entrée.
f. Il ___ de café dans cette rue.
g. Elle ___ d’ordinateur chez elle.
h. On ___ d’information à ce sujet.

**[A1 (inferred)]**
### 20 Posez des questions avec les éléments donnés et le verbe *avoir*.

Exemple : Tu / un stylo. → Est-ce que tu as un stylo ?

a. Vous / vos papiers. → ___
b. Tu / des enfants. → ___
c. Je / le temps. → ___
d. Ils / toutes les informations. → ___
e. Elle / un bon travail. → ___
f. Nous / faim. → ___

**[A1 (inferred)]**
### 21 Mettez dans l’ordre.

Exemple : a / Il / pas / chance. / de / n’ → Il n’a pas de chance.

a. voiture ? / nouvelle / Vous / une / avez → ___
b. n’ / pas / Je / ai / temps / finir. / le / de → ___
c. Tu / son / as / mail ? / pas / n’ → ___
d. demain / ont / enfants / Les / école. → ___
e. avez / excellente / Vous / idée ! / une → ___

**[A1 (inferred)]**
### 22 Trouvez la question correspondant à la réponse. (Plusieurs possibilités.)

Exemple : Est-ce que vous avez / tu as le plan du métro ? ← Oui, j‘ai le plan de métro. <!-- sic: apostrophe in "j‘ai" printed as an opening quote ‘; "plan de métro" in the answer vs "plan du métro" in the question -->
