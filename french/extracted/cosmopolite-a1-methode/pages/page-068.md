## 🔀 FOCUS LANGUE　▸ p. 208

**Avoir mal à + les parties du corps**

**a.** Observez la fiche (activité 7). Associez.
1. *J'ai mal au* +　　a. nom pluriel.
2. *J'ai mal à la* +　　b. nom féminin.
3. *J'ai mal à l'* +　　c. nom masculin.
4. *J'ai mal aux* +　　d. nom masculin ou féminin commençant par une voyelle.

**b.** Complétez avec les parties du corps.

[Illustration : silhouette d'un homme torse nu en short bleu, vue de face et vue de dos, avec des lignes de légende pointant vers différentes parties du corps]

Vue de face : deux lignes convergeant vers le visage → **la bouche** ; ligne vers le cou → **la gorge** ; ligne vers le haut du torse (sans légende, à compléter) ; ligne vers le bas de l'abdomen (sans légende, à compléter) ; ligne vers la main → **la main** ; ligne vers le genou → **le genou** ; ligne vers le pied/la cheville (sans légende, à compléter).

Vue de dos : ligne vers le bras → **le bras** ; ligne vers le dos → **le dos**.

**c.** En groupe :
– levez-vous et formez deux lignes, une ligne en face de l'autre ;
– à tour de rôle, mimez où vous avez mal.
La personne en face de vous devine où vous avez mal.
Exemple : *Tu as mal au dos ?*
