**> FOCUS LANGUE** &nbsp; ▶ p. 217

**Quelques marqueurs temporels du passé (2)**

**a.** Relisez ces extraits. Observez les marqueurs temporels.

| | | |
|---|---|---|
| Vous avez fondé l'association **il y a** quelques années. | 1995 —✕— dans le passé ——— aujourd'hui | |
| J'ai grandi en Amérique latine **pendant** <u>sept ans</u>. | de 2000 à 2007 ━━ dans le passé ——— aujourd'hui | |
| **Depuis** <u>1920</u>, l'école Ferrandi forme de futurs chefs. | 1920 ✕┄┄┄┄┄┄→ dans le passé &nbsp; aujourd'hui | |
| **Avant**, elles étaient journalistes. | avant (dans le passé) / aujourd'hui | |
| **Quand** j'étais infirmière, je m'ennuyais. | ┃infirmière┃ dans le passé ——— aujourd'hui | |

*(dans l'encadré, chaque frise chronologique va d'un point/segment coloré à gauche — représentant « dans le passé » — vers le mot « aujourd'hui » en orange à droite ; les mots-clés « il y a », « pendant », « Depuis », « Avant », « Quand » sont mis en couleur dans le texte de gauche)*

**b.** Donnez un exemple personnel pour chaque marqueur temporel.
Exemples : *J'étudie le français* **depuis** *trois mois. Avant, je ne parlais pas français. Aujourd'hui, je parle un peu français.*
