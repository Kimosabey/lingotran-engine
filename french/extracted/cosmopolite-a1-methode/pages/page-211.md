**Les noms de profession**

▶ D1 L3 p. 25 – D3 L4 p. 63

| Masculin | Féminin | |
|---|---|---|
| un comédien | une comédienne | -ien / -ienne |
| un réalisateur | une réalisatrice | -teur / -trice |
| un coiffeur | une coiffeuse | -eur / -euse |
| un infirmier | une infirmière | -er / -ère |
| un journaliste | une journaliste | -e / -e |

**Attention !** *Un chanteur, une chanteuse.*

#### 2. Les noms de pays

▶ D0 L3 p. 14 et 15

| | | |
|---|---|---|
| Masculin | les noms de pays qui se terminent avec d'autres lettres que le *e* et le *s* | le Japon<br>le Brésil<br>l'Iran |
| Féminin | les noms de pays qui se terminent avec la lettre *e* | la Chine<br>la Hongrie<br>l'Australie |
| Pluriel | les noms de pays qui se terminent avec la lettre *s* | les États-Unis<br>les Pays-Bas<br>les Philippines |

**Attention !** Il existe quelques exceptions :
*le Mexique, le Cambodge, le Zimbabwe, le Mozambique.*

**Attention !** On n'utilise pas d'article devant certains noms de pays : *Cuba, Singapour, Madagascar, Chypre, Malte, Haïti.*

### Les adjectifs qualificatifs

Les adjectifs s'accordent en genre et en nombre avec le nom.

▶ D1 L3 p. 25 – D3 L2 p. 59 – D5 L4 p. 99

| blond* | blonde | |
| petit* | petite | |

| fort* | forte | + e |
| gris* | grise | |

| Masculin | Féminin | |
|---|---|---|
| sportif | sportive | -if / -ive |
| curieux<br>heureux | curieuse<br>heureuse | -eux / -euse |
| sincère<br>calme<br>russe | sincère<br>calme<br>russe | masculin = féminin** |
| brésilien<br>italien | brésilienne<br>italienne | + ne |
| exceptionnel<br>maternel | exceptionnelle<br>maternelle | + le |

\* Les consonnes *d, s, t* sont muettes au masculin mais sonores au féminin.

\*\* Si le masculin se termine par *e*, le féminin est identique.

**Attention !** *Un homme turc, une femme turque.*  *Un vin blanc, une veste blanche.*
