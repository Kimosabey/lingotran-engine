## 🔀 FOCUS LANGUE　▸ p. 218

**Le verbe *faire* + *du* / *de la* / *de l'* / *des* pour parler de ses activités**

**a.** Observez vos réponses à l'activité 5. Complétez la règle.

*faire*　{　– … + nom masculin
　　　　– … + nom féminin
　　　　– … + nom masculin ou féminin qui commence par une voyelle
　　　　– … + nom pluriel　}

**Attention !** Avec la négation : *Je ne fais pas de/d'.*
*Je ne fais pas de voile / pas de théâtre / pas d'équitation.*

**b.** 🎧 n°74 Écoutez le verbe *faire*.
Associez à la prononciation correspondante.

je fais　→　2. [fɛ] *(exemple : flèche tracée de « je fais » vers « 2. [fɛ] »)*
tu fais　　1. [fɛt]
il/elle fait　　2. [fɛ]
nous faisons　　3. [fəzɔ̃]
vous faites　　4. [fɔ̃]
ils/elles font
