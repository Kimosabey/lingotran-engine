**8. Sons du français**　▶ p. 204

**Le son [ø] pour dire *on veut***

**a.** 🎧 H90 Écoutez. Vous entendez le son [ø] dans le premier mot, montrez 1. Vous entendez le son [ø] dans le deuxième mot, montrez 2. Puis répétez le mot.
Exemple : *douze – deux* → **2**

Pour prononcer les lettres *eu* en français, il y a deux possibilités : [ø] et [œ].
Exemple : *il v<u>eu</u>t* [ø] (la bouche est un peu fermée) – *ils v<u>eu</u>lent* [œ] (la bouche est un peu ouverte).

**b.** 🎧 H91 Écoutez. Vous entendez le son [ø], levez la main.
Exemple : *On p<u>eu</u>t parler français.*
→ *Vous entendez [ø], levez la main.*　▶ p. 177

> **Les verbes *pouvoir*, *devoir* et *vouloir* au présent**
>
> **a.** Complétez.
> peut • veut • doivent • dois • voulez • veux • peux • pouvez • dois • doit • veux • peux • devez • veulent • peuvent

| Pouvoir | Devoir | Vouloir |
|---|---|---|
| je … | je … | je … |
| tu … | tu … | tu … |
| il/elle/on … | il/elle/on … | il/elle/on … |
| nous pouvons | nous devons | nous voulons |
| vous … | vous … | vous … |
| ils/elles … | ils/elles … | ils/elles … |

**Attention !** Les verbes *vouloir*, *pouvoir* et *devoir* sont suivis d'un verbe à l'infinitif.
