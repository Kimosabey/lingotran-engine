**4. Sons du français** &nbsp; ▶ p. 202

**Le son [y]**

**a.** [icône casque audio n°13] &nbsp; Fermez les yeux. Écoutez les phrases. Vous entendez [y] dans la première syllabe, montrez 1 ; dans la deuxième syllabe, montrez 2 ; dans la troisième syllabe, montrez 3.
Exemple : *Salut Anne !* → 2

**b.** [icône casque audio n°14] &nbsp; Écoutez. Vous entendez [y], saluez de manière informelle. Vous entendez [u], saluez de manière formelle. &nbsp; ▶ p. 163
