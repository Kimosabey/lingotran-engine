**Les accents pour épeler**

Observez.

| | |
|---|---|
| Accent aigu ( ´ ) | seulement avec *e* (*é*) |
| Accent grave ( ` ) | avec *a* (*à*), *e* (*è*), *u* (*ù*) |
| Accent circonflexe ( ^ ) | avec *a* (*â*), *e* (*ê*), *i* (*î*), *o* (*ô*), *u* (*û*) |
