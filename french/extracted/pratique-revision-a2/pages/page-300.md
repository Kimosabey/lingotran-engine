### 561 Dites si c’est correct ou non. Si ce n’est pas correct, faites la correction.

| Affirmation | Correct | Pas correct | |
|---|---|---|---|
| a. Ce soir, je vais rentrer jusqu’à 6h. | [ ] | [x] | Ce soir, je vais rentrer à 6h. |
| b. En général, Édith travaille de lundi au jeudi. | [ ] | [ ] | ___ |
| c. Le lundi, je ne vais jamais à la gym. | [ ] | [ ] | ___ |
| d. Au juin, les journées sont très longues. | [ ] | [ ] | ___ |
| e. Valérie passera nous voir vers midi. | [ ] | [ ] | ___ |
| f. À partir du vendredi, le magasin sera fermé pour les vacances annuelles. | [ ] | [ ] | ___ |
| g. Nous serons absents jusqu’au juin. | [ ] | [ ] | ___ |
| h. Virginie est née en automne, n’est-ce pas ? | [ ] | [ ] | ___ |

(marked, example: a. → Pas correct ; correction : Ce soir, je vais rentrer à 6h.)
