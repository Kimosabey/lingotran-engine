### 202 Trouvez le mot qui correspond à la définition.

Exemple : Une personne qui vous conseille sur un traitement médical : pharmacien/ne.

a. Une solution liquide très sucrée : ___
b. Une infection de la gorge : ___
c. Médicament qui permet de mieux dormir : ___
d. Une personne qui pratique des soins, sous la direction d’un médecin : ___
e. Une compresse qui sert à protéger une petite blessure : ___
f. Rétabli d’une maladie : ___

> **• Le personnel de santé (= les soignants), les spécialistes**
> [Audio track 62]
>
> Si votre maladie est très spécifique, le médecin peut vous recommander de voir un spécialiste : un(e) **ophtalmologue** pour les yeux, un(e) **cardiologue** pour le cœur, un(e) **pédiatre** pour les enfants, un(e) **dermatologue** pour les problèmes de peau, un(e) **gynécologue** pour les femmes… Si vous avez mal aux dents, vous devez aller directement chez le/la **dentiste**.
> Si votre maladie est plus sérieuse, ou/et si vous avez eu un **accident** et que vous êtes **blessé** (= **le sang** coule), le médecin peut décider de vous **hospitaliser** : vous allez entrer à l’**hôpital**. Si vous avez une **fracture** (vous avez la jambe cassée, le bras cassé…), vous allez être **plâtré** (avoir le bras dans le **plâtre**). Si une **opération** est nécessaire, un(e) **chirurgien(ne)** va vous opérer dans une salle d’**opération**. Avant l’opération, une **anesthésie** est pratiquée pour vous endormir (c’est l’**anesthésiste** qui intervient).
> Souvent, après un accident (par exemple une jambe cassée), une période de rééducation est recommandée : vous allez voir un(e) **kiné** (c’est l’abréviation de kinésithérapeute) qui vous aide à faire des mouvements et à récupérer votre mobilité.
