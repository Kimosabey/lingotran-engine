Grammaire/Conjugaison

> **• Devant / derrière / entre / parmi / par / vers**
>
> **Nous passons devant la vitrine. Ne passe pas devant, reste derrière moi. Nous habitons Nîmes, à mi-chemin entre Avignon et Montpellier. Je suis sûr qu’il y aura un volontaire parmi nous. Avant de partir passe par chez nous. J’ai eu peur quand j’ai vu l’animal venir vers moi.** <!-- sic: "habitons Nîmes" without "à" -->
>
> • **Entre** + nom ou pronom tonique indique une position intermédiaire.
> • **Par** + nom indique un lieu qu’on traverse pour aller à un autre lieu.
> • **Devant** + nom ou pronom tonique indique la position frontale, visible du locuteur.
> • **Vers** + nom ou pronom tonique indique la direction.
> • **Parmi** + nom ou pronoms toniques pluriels indique une position à l’intérieur d’un groupe.
> • **Derrière** + nom ou pronom tonique indique une position qui n’est pas visible du locuteur.

### 604 Complétez avec entre, parmi, devant ou derrière.

Exemple : On le voyait toujours passer devant chez nous.

a. Trois-Rivières, c’est une ville qui se situe ___ Québec et Montréal.
b. Bamako, Lomé, Trois-Pistoles ___ ces villes, laquelle n’est pas en Afrique ?
c. Impossible de le voir : il était caché ___ l’arbre.
d. Comme tu fais pour ne pas le voir s’il est juste ___ toi ?! <!-- sic: "Comment" expected -->
e. Un candidat sera choisi ___ les cinq ou six à s’être présentés.
f. Je pensais être le premier. Pas de chance ! Il y avait déjà une bonne centaine de personnes ___ moi.
g. Il y avait un petit jardin qu’on ne voyait pas de la rue parce qu’il était ___ la maison.

### 605 Cochez la forme qui convient.

Exemple : Cette porte est fermée, passe
[ ] entre celle du garage.
[x] par celle du garage.
[ ] vers celle du garage.
(marked, example: par celle du garage.)

a. Vous prenez tout droit
[ ] entre la pharmacie que vous voyez là-bas.
[ ] parmi la pharmacie que vous voyez là-bas.
[ ] vers la pharmacie que vous voyez là-bas.

b. Avant de rentrer, n’oublie pas de passer
[ ] par la boulangerie pour acheter une baguette.
[ ] entre la boulangerie pour acheter une baguette.
[ ] devant la boulangerie pour acheter une baguette.

c. C’est le seul endroit vraiment sympa qu’on a proposé
[ ] parmi toutes les options qu’il y avait.
[ ] par toutes les options qu’il y avait.
[ ] entre toutes les options qu’il y avait.

d. Je pensais gagner la course mais elle est passée
[ ] derrière moi à une dizaine de mètres de l’arrivée.
[ ] devant moi à une dizaine de mètres de l’arrivée.
[ ] par moi à une dizaine de mètres de l’arrivée.
