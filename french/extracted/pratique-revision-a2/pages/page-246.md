### 456 Reliez les verbes à leur complément logique et formulez des phrases complètes.

| Verbe / sujet | Complément |
|---|---|
| Falloir / il | Flûte |
| Avoir / nous | Énergie |
| Acheter / elles | Thé / matin |
| Prendre / je | Sculpture |
| Boire / tu | Prunes / supermarché |
| Faire / elle | Œufs / omelette |
| Manger / vous | Toasts / petit déjeuner |
| Jouer / ils | Sucre / café |

(marked, example: Falloir / il → Œufs / omelette)

Exemple : Il faut des œufs pour faire une omelette.
