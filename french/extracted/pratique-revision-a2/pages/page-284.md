# 22 • L’interrogation, l’interro-négation

<!-- running header -->
Grammaire/Conjugaison

> **• Les différents types de questions (révision)**
>
> **Tu habites à Lyon ? Tu habites où ?**
>
> • Est-ce que tu fais du basket ? Avez-vous des enfants ? Ce sont des questions fermées, réponse : oui/non
>
> • Où tu habites ? Pourquoi est-ce que tu es en retard ? Quand sont-ils arrivés ? Ce sont des questions ouvertes, avec un mot interrogatif
>
> **Mots interrogatifs** [Illustration : schéma en étoile autour de « Mots interrogatifs »]
> - qui (personnes)
> - où (lieu)
> - que (objets, choses)
> - comment (manière)
> - quand (moment)
> - combien (quantité ou prix)
> - pourquoi (cause, objectif)
>
> [main / attention] « que » se transforme en « quoi » quand il est en position finale. *Tu fais quoi ?* (~~tu fais que~~ ? )

### 530 Dites si c’est une question ouverte ou fermée.

| | |
|---|---|
| Question ouverte | a. Tu t’appelles comment ? |
| Question fermée | b. Vous voulez sortir ? |
| | c. Est-ce qu’ils sont partis ? |
| | d. Nous partons quand ? |
| | e. Aimez-vous la science-fiction ? |
| | f. Pourquoi a-t-elle démissionné ? |
| | g. Quand est-ce que nous irons à la montagne ? |
| | h. Vous faites quoi ce soir ? |

(marked, example: Question ouverte → a)

### 531 Combien ou comment ? Placez le mot interrogatif correct dans chaque question.

Exemple : Vous avez écrit combien de paragraphes ?

a. ___ tu as payé pour ce joli pull ?
b. ___ de temps il faut pour aller à l’université ?
c. Et ___ on y va ?
d. ___ est-ce qu’on dit « pomme » en italien ?
e. C’est ___, ce stylo, s’il vous plait ?
f. Tu l’as trouvé ___, ce film ?
g. ___ allez-vous aujourd’hui ?
