19 • L’expression de la quantité

### 464 Possible, pas possible ? Barrez l’option impossible.

Exemple : Un seau ~~*de pain*~~ / *d’eau* / *de terre*

a. Une carafe *de vin* / *d’eau* / *de cacahuètes*
b. Un pot *de fleurs* / *de moutarde* / *de poulet*
c. Un verre *de melons* / *de soda* / *de lait*
d. Un gramme *de pomme de terre* / *de sel* / *d’origan*
e. Un litre *d’œufs* / *de crème* / *de confiture*
f. Une bouteille *de gaz* / *d’épices* / *d’huile*
g. Un sac *de bonbons* / *de pommes* / *de vinaigre*
