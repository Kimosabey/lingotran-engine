Grammaire/Conjugaison

> **• Les adjectifs démonstratifs (1)**
>
> **Un pull jaune ? Ah non, je déteste les pulls de cette couleur !**
>
> | | Masculin | Masculin qui commence par une voyelle ou un h « muet » | Féminin |
> |---|---|---|---|
> | **Singulier** | ce stylo | cet homme | cette idée |
> | **Pluriel** | ces stylos / hommes / idées | | |
>
> • Pour désigner plus précisément dans le temps, on peut employer les formes
> -ci (proximité) : Ces jours-ci…
> -là (éloignement) : À cette époque-là…
> • Ces formes sont utilisées aussi pour indiquer une option : *Tu veux ce livre-ci ou ce livre-là ?*
> • Pour indiquer la distance dans l’espace, on préfère employer là-bas : ce chemin là-bas.
