### 655 Reliez les éléments des deux colonnes avec « pour » ou « mais ».

| | | |
|---|---|---|
| a. Manger des fruits c’est important | Mais | 1. obtenir une bourse d’études. |
| b. Au cinéma, on ne doit pas téléphoner | Pour | 2. il faut aussi la pratiquer. |
| c. Il faut combien de temps | | 3. je ne suis pas d’accord avec cette proposition. |
| d. C’est bien d’étudier une langue | | 4. aller sur Mars ? |
| e. La température diminue en janvier | | 5. célébrer mon anniversaire. |
| f. Nous sommes allés dans un escape room | | 6. on doit aussi boire de l’eau. |
| g. Vous avez peut-être raison | | 7. les jours rallongent. |
| h. Il faut remplir beaucoup de documents | | 8. beaucoup de gens le font. |

(marked, example: a → Mais → 6)
