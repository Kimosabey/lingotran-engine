> **• Les superlatifs**
>
> **Le lac Baïkal est le lac le plus profond du monde (adjectif). • L’activité que je fais le moins souvent est la natation (adverbe). • La Chine est le pays qui a le plus d’habitants au monde (nom). • De tous mes amis, Marc est celui qui parle le moins (verbe).**
>
> • Le superlatif permet d’exprimer un degré maximum ou minimum : le superlatif de supériorité et d’infériorité. Il peut porter sur un adjectif (le, la, les + plus/moins + adjectif), un adverbe (le + plus/moins + adverbe), un nom (le + plus de/d’ / moins de / d’ + nom), un verbe (verbe + le plus/le moins).
>
> [main / attention] le (+) bon > le meilleur, la meilleure, les meilleurs, les meilleurs <!-- sic: "les meilleures" expected for the feminine plural -->
>
> [main / attention] le (+) mauvais > le (la, les) plus mauvais, mauvaise/s ou le, la, les pire/s
>
> [main / attention] le (+) bien > le mieux

### 525 Placez ces adjectifs, adverbes, noms ou verbes dans les phrases suivantes.

lisent - huile - chante - vite - Ballons d’or - tue - intelligente

Exemple : Edgar est l’élève qui chante le mieux dans son école.

### 526 Complétez les questions de ces deux enquêtes avec le superlatif. N’oubliez pas d’accorder les adjectifs et de conjuguer les verbes.

Exemple : Quelle personne tu admires le plus ? (+/admirer)

**Enquête 1 : personnalité**

a. Quelle est ___ expérience de ta vie ? (+/bon)
b. Quelle est la décision ___ de ta vie ? (+/difficile)
c. Quelle personne de ta famille est ___ dans ta vie ? (-/présent)
d. Qui a ___ sur toi ? (+/influence)
e. Quelle profession t’___ ? (+/intéresser)

**Enquête 2 : autour de soi**

f. Qu’est-ce qui fonctionne ___ dans ton pays ? (-/bien)
g. Qu’est-ce qui est ___ à faire dans ta ville ? (+/urgent)
h. Quel pays a ___ pour toi ? (+/problème)
