### 427 Remettez dans l’ordre les éléments des phrases.

Exemple : – Nous avons essayé mais ça ne marchait pas.
– Ne vous inquiétez pas *entrer / pouvoir / allez / dans le système / sans problème / vous / maintenant*
Ne vous inquiétez pas, maintenant vous allez pouvoir entrer dans le système sans problème.

a. – Son avion est arrivé ?
– Non, *avec au moins 30min / il / atterrir / de retard. / va*
___
b. – Vous avez fini votre travail ?
– Presque, *notre présentation / va / avant de la rendre. / relire / on / mais*
___
c. – Elles y vont en voiture ?
– D’habitude oui, *cette fois-ci / vont / mais / là-bas / aller / en train. / elles*
___
d. – Vous avez mangé ?
– Non, pas encore. *d’ici / manger / on / une petite heure. / va*
___
e. – Nous pouvons entrer dans le logiciel ?
– Normalement non, *je / un compte / créer / mais / rien que pour vous. / vais*
___
f. – Vos nouveaux voisins sont installés ?
– Pas encore. *en principe. / ils / le weekend prochain / arriver / vont*
___
g. – Il est venu tout seul ?
– Oui, *chercher / à l’école / aujourd’hui. / il / parce qu’ / va / les enfants*
___
h. – Tu n’as pas encore terminé ?
– Non, *un effort / pour terminer / faire / je / d’ici à lundi prochain. / vais*
