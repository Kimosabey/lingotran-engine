24 • Localisation dans l’espace

### 599 Cochez la forme qui convient.

Exemple : Toute l’info est disponible…
[x] en ligne.
[ ] dans la ligne.
[ ] sur la ligne.
(marked, example: en ligne)

a. Je n’arrive pas à lire le texte
[ ] dans mon écran.
[ ] sur mon écran.
[ ] sous l’écran.

b. Il n’est pas disponible en ce moment, il est
[ ] sur une visio.
[ ] en visio.
[ ] dans une visio.

c. C’est une vraie influenceuse : elle est présente
[ ] en tous les réseaux sociaux.
[ ] dans tous les réseaux sociaux.
[ ] sur tous les réseaux sociaux.

d. Avons-nous vraiment raison de garder tous nos renseignements personnels
[ ] sur le nuage ?
[ ] dans le nuage ?
[ ] en nuage ?

e. Toutes les vidéos se trouvent
[ ] en plateforme.
[ ] sur la plateforme.
[ ] dans la plateforme.

f. Vous pouvez poser directement toutes vos questions
[ ] en chat.
[ ] dans le chat.
[ ] sur le chat.

g. Elle avait toutes ses photos
[ ] au téléphone qu’elle a perdu.
[ ] dans le téléphone qu’elle a perdu.
[ ] sur le téléphone qu’elle a perdu.

h. On trouve toutes ces infos
[ ] dans internet.
[ ] en internet.
[ ] sur internet.

> **Les points cardinaux : à ou *dans* ?**
> La Villette et le Sacré-Coeur se trouvent dans le nord de Paris mais Saint-Denis et Sarcelles sont des villes qui sont au nord de Paris. En fonction de la position qu’on occupe, on peut se situer à l’intérieur ou à l’extérieur d’un point cardinal (l’est, le nord, l’ouest, le sud).
