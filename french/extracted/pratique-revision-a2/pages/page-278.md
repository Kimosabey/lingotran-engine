| | vrai | faux |
|---|---|---|
| Exemple : Appartement (4 pièces) - Studio (1 pièce) : Cet appartement a moins de pièces que ce studio | [ ] | [x] |
| a. Istambul (15 millions d’habitants) – Buenos Aires (15 millions d’habitants) : Istambul a plus d’habitants que Buenos Aires. | [ ] | [ ] |
| b. Rasmus (150 points) – Valeri (198 points) : Rasmus a gagné moins de points que Valeri à la compétition. | [ ] | [ ] |
| c. Mur (35 photos) - Album (75 photos) : Il y a plus de photos dans l’album que sur le mur. | [ ] | [ ] |
| d. Mimi (12 bonbons) – Lala (11 bonbons) : Mimi a mangé autant de bonbons que Lala. | [ ] | [ ] |
| e. Cuisine (1 fenêtre) – Salon (3 fenêtres) : Il y a moins de fenêtres dans la cuisine que dans le salon. | [ ] | [ ] |
| f. Milk-shake (50g de chocolat) – Brownie (100g de chocolat) : Il faut autant de chocolat pour faire un milk-shake que pour faire un brownie. | [ ] | [ ] |
