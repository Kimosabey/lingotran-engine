### 403 Associez le pronom à la forme verbale qui convient.

| | |
|---|---|
| Je | roulait à toute vitesse. |
| Tu | préféraient aller en vacances à la campagne. |
| La voiture | souhaitions bonne chance aux candidats. |
| Nous | posais plein de questions pour comprendre. |
| Vous | révisais mes notes pour l’examen. |
| Ils | alliez lui rendre visite. |

(marked, example: Je → révisais mes notes pour l’examen.)

### 404 Réécrivez ces phrases au pluriel.

Exemple : Je pensais passer le mois d’août sur la côte. → Nous pensions passer le mois d’août sur la côte.
